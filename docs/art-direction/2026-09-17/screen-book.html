How this screen should work

Routes and acceptance criteria

The game-wide rules

  1. Navigation belongs in the game frame. Top game menu, persistent wide-screen rail, full-height compact menu. No bottom website tabs.
  2. Density serves decisions. One table header, compact rows, named metrics, relevant column presets. Details live in the inspector.
  3. Art establishes place. Miniature environments in welcome and phase moments; stable cel faces where people matter. Keep decision surfaces quiet.
  4. Scrolling stays usable. Wheel, touch and keyboard still work. Dense tables offer explicit column controls; no native scrollbar rails.
  5. Truth is visible. Unknown statistics, pending approval, private scouting and failed saves remain distinct states.
